# Data Model: 图的颜色模型

本 feature 没有持久化数据，也没有新的运行时对象。"数据模型"指三样东西：**角色**（图形在流程图里承担什么职能）、**色相来源**（用宿主哪个令牌）、**派生变量**（由前两者算出的填充/描边）。三者都是编译期常量，运行期唯一变化量是宿主主题。

## 1. 图形角色（role）

引擎为每个 flowchart 节点输出 `<g class="pele-node pele-shape-X">`，`X` 由源文本的括号形状决定，是稳定信号（实测 13 种，见 [research.md](./research.md) R7）。

| 字段 | 说明 |
| --- | --- |
| `name` | `start-end` / `decision` / `data` / `io` / `process` |
| `label` | 文档与检查里用的中文名：起止、判断、数据、输入输出、处理 |
| `syntax` | 读者（模型）写出的源文本形状，如 `([..])`、`{..}`、`[(..)]`、`[/../]`、`[..]` |
| `shapeClasses` | 引擎输出的类名，如 `stadium`、`diam`、`cyl`、`lean-r`、`rect` |
| `hue` | 色相来源：一个宿主令牌的引用 |
| `fill` / `stroke` | 由 `hue` 按 D1 公式派生 |

### 角色表

| 角色 | 源文本 | 形状类 | 色相令牌（宿主） |
| --- | --- | --- | --- |
| 起止 start-end | `A([..])`、`A((..))`、`A(..)` | `stadium`、`circle`、`odd` | `--dsw-static-green-500` |
| 判断 decision | `B{..}`、`B{{..}}` | `diam`、`hex` | `--dsw-static-amber-500` |
| 数据 data | `C[(..)]` | `cyl` | `--dsw-static-violet-400` |
| 输入输出 io | `D[/../]`、`D[\..\]`、`D[/..\]`、`D[\../]` | `lean-r`、`lean-l`、`trap-b`、`trap-t` | `--dsw-alias-link` |
| 处理 process | `E[..]`、`E(..)`、`E[[..]]` | `rect`、`rounded`、`fr-rect` | `--dsw-static-neutral-bluish-400`（非彩色角色，靠明度分档） |

规则：
- **同类同色**：同一 `shapeClasses` 集合内的成员共享一对填充/描边（FR-004）。
- **两两不等**：五个角色的填充互不相同（取值互异是硬要求）。
- **四色相 + 一明度档**：起止/判断/数据/输入输出各自取色相，彩色通道差 20–42（检查断言 ≥20，相邻角色对色相差 ≥20°）；处理类刻意不取色相，只借 `label-primary` 的明度台阶与背景分开（填充对背景 >1.05、描边对背景 ≥3:1）。这是为了不让流程图里最多的框抢走注意力，同时满足 FR-012 的"至少四类各自成色"。宿主可用的彩色族只有 amber/blue/deepseek/green/red/violet 六族，其中 blue 与 deepseek 色相仅差 6°，无法撑起第五个可区分的色相。
- **只认形状，不认同义词**：源文本里写什么词都不影响颜色；只有形状变，颜色才变。文档必须讲清这一点（SC-009）。

## 2. 派生变量（`color-mix` 公式）

```
fill   = color-mix(in srgb, <hue> 18%, var(--pele-bg))
stroke = color-mix(in srgb, <hue> 60%, var(--pele-fg))
```

`--pele-bg` = `--dsw-alias-bg-layer-1`，`--pele-fg` = `--dsw-alias-label-primary`。两者都随主题翻转，因此同一公式在两套主题下自动落在可读区间——这正是 D2 的解法：**浅色混黑、深色混白**，不按主题切比例。

## 5. 校验规则（写进检查的硬约束）

1. 样式表里**不得**出现 `#rrggbb` / `rgb()` / `hsl()` 字面色值——颜色只能来自 `var(--dsw-*)` 或它们的 `color-mix` 派生。
2. 样式表里**不得**出现 `!important`——作者 `classDef` 的行内样式必须天然优先（FR-010）。
3. 选择器**不得**以 `body`、`:root`、`html` 起头，也不得引用宿主的主题属性选择器（如 `[data-ds-dark-theme]`）——不接管宿主 DOM、不自建第二套主题。
4. 填充/描边规则只作用于形状图元（`rect`/`path`/`circle`/`polygon`/`ellipse`/`polyline`），**不作用于** `text`——文字颜色保持 `--pele-fg`。
5. `--pele-bg`/`--pele-fg`/`--pele-muted`/`--pele-surface-alt`/`--pele-critical`/`--pele-font` 保持现有映射，只允许被本表明确列出的改动替换。
