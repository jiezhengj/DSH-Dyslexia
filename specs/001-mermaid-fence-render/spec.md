# Feature Specification: 会话内图形渲染

**Feature Branch**: `001-mermaid-fence-render`

**Created**: 2026-11-22

**Status**: Implemented（代码与自动化证据截至 `0.1.7`），但**不是全部取证**。没有取证的项一律以 `evidence/verification.md` 的 **E-GAPS（12 项，G1–G12）** 为准，`tasks.md` 末尾的状态表逐行对应；本行不重复计数，以免与 E-GAPS 漂移。真机证据 E-LIVE 目前是 **0.1.2** 的观察，0.1.7 的复核是 T079。

**Input**: User description: "做一个 DSH 插件（npm 包 `@jiezhengj/dsh-dyslexia`），让 Agent 画的 mermaid 图直接渲染在会话流里；不假设用户机器装了什么，依赖打包进插件；不规定图表类型与文本长短；卸载后历史会话仍要能读；手机平板要能用。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 图直接出现在会话里 (Priority: P1)

读者有阅读障碍，读大段文字吃力但读图几乎无负担。当 Agent 把关系、流程、层级或对比写成 mermaid 代码块时，会话流里那块源码直接变成图，读者不用打开侧栏、不用另存文件，也不用离开当前会话。

**Why this priority**: 这是整个功能存在的理由——把"读长文"换成"看图"，且图必须留在会话这个阅读现场。

**Independent Test**: 在含 mermaid 代码块的会话里观察该代码块位置是否显示为图，且会话内不出现新的文件、不打开侧栏。

**Acceptance Scenarios**:

1. **Given** 会话中有一条 Agent 消息含符合语法的 mermaid 代码块，**When** 消息渲染完成，**Then** 该代码块位置显示为图，其余消息内容与顺序不变。
2. **Given** 同一会话里有多张图，**When** 逐条查看，**Then** 每张图各自独立渲染，互不影响。
3. **Given** 读者想核对图对应的原始描述，**When** 触发"查看源码"，**Then** 能看到该图的完整 mermaid 文本并可复制。

---

### User Story 2 - 卸载插件后历史仍然可读 (Priority: P2)

读者试用后决定卸载插件。她重新打开几周前的会话，看到的不应是空白、报错或"缺失内容"，而是完整可读、可检索的文本。

**Why this priority**: 会话是长期资产；插件的去留不应改变历史内容的可用性。这是最容易在事后暴露、也最难补救的一类损坏。

**Independent Test**: 卸载插件后重开会话，检查旧 mermaid 代码块是否以完整文本呈现且可复制、可被会话检索命中。

**Acceptance Scenarios**:

1. **Given** 历史会话含已渲染过的图，**When** 插件被卸载并重新打开该会话，**Then** 原图位置显示为完整 mermaid 文本代码块，无报错、无占位空白。
2. **Given** 插件被卸载，**When** 在此状态新建会话并让 Agent 表达结构信息，**Then** 不产生"只有装了插件才看得懂"的内容。

---

### User Story 3 - 手机上读图不加倍费力 (Priority: P2)

读者常在手机上继续会话。长流程、宽表格型的图在窄屏上必须仍然读得懂：按屏宽重新排布，而不是把整张图挤成一小块。

**Why this priority**: 阅读障碍读者本就依赖版式；在手机上图被压缩到不可读等于没有这个功能。

**Independent Test**: 以手机宽度浏览含图会话，检查页面不横向溢出、图内文字不小于正文、超大图可在图内缩放或平移。

**Acceptance Scenarios**:

1. **Given** 视口宽度约 360 像素，**When** 浏览含图会话，**Then** 页面本身不出现横向滚动，图按容器宽度重新排布。
2. **Given** 一张超出屏宽的复杂图，**When** 在触屏上操作，**Then** 可在图内放大、缩小与复位，且缩放不改变会话其余部分的布局。

---

### User Story 4 - 不装东西、不联网也能用 (Priority: P3)

读者的电脑上只有 DSH 本身，没有 Node、Python 或其他工具链，宿舍网络也不稳。插件装好即用，渲染时不请求任何外部资源。

**Why this priority**: 影响可用性下限；一旦需要额外安装步骤，插件在陌生机器上就会"装了但不显示"。

**Independent Test**: 在断网状态下、且未安装任何额外运行时的情况下完成一次完整渲染。

**Acceptance Scenarios**:

1. **Given** 设备断网且没有任何额外语言运行时，**When** 打开含图会话，**Then** 图正常显示。
2. **Given** 渲染过程，**When** 观察网络请求，**Then** 不产生任何外部请求。

---

### User Story 5 - DSH 升级不会把应用拖到打不开 (Priority: P1)

读者装了这个插件之后，DSH 会继续升级。升级后最坏的情况不是"图不画了"，而是整个应用起不来、连界面都进不去，甚至连"禁用插件"都无从操作。插件必须保证：无论宿主版本怎么变、接口怎么改，它最多让自己不工作，绝不能让 DSH 打不开。

**Why this priority**: 与 US1 同级——一个把宿主弄坏的功能，装得越省事、坏得越彻底；这类故障恰恰发生在用户最没有补救手段的时候。

**Independent Test**: 用畸形/变化过的宿主接口喂给插件（缺服务、接口签名变化、加载器抛错、渲染抛错），观察宿主是否照常启动与渲染，插件是否只是安静地不画。

**Acceptance Scenarios**:

1. **Given** 包清单里不含任何版本否决字段，**When** 宿主版本升级到清单作者从未见过的版本，**Then** 宿主不会因本插件拒绝启动。
2. **Given** 宿主在加载客户端模块时抛错、或缺少全局加载器，**When** 加载本插件的客户端产物，**Then** 该产物自身不抛出，宿主其余插件不受影响。
3. **Given** 宿主提供的服务缺失或接口签名改变（槽注册、本地化、翻译函数、上下文对象），**When** 插件启动，**Then** 插件安静降级为"不渲染"，不抛错、不阻断其余插件。
4. **Given** 宿主派发的围栏数据结构不符合预期，**When** 渲染该处，**Then** 交回宿主原本的代码块，会话其余部分照常。

---

### Edge Cases

- **语法错误的 mermaid**：必须回退为该代码块原文，并给出可读的原因提示，而不是空白或报错占位。
- **流式输出中的半截代码块**：代码块未闭合期间不得闪烁为空图或错误；输出完成后渲染一次。
- **超大图**（节点或边数量极大）：不得卡死或撑破页面；超限时回退为文本并说明原因。
- **深浅主题切换**：图配色跟随宿主主题变化，无需刷新页面。
- **同一消息里代码块与普通文本混排**：只替换代码块本身，周围文本、列表、表格保持原样。
- **代码块语言标记不是 mermaid**：不渲染，原样显示。
- **宿主把插件当"不兼容"处理**（清单里出现版本否决字段）：这是本功能明令禁止的故障形态，构建期就要拦住；见 FR-013 与 SC-007。
- **宿主接口变化**（槽位消失、注册签名改变、服务缺失、翻译函数签名改变、围栏字段变化）：插件安静地不渲染，应用与其余插件照常；见 FR-014～FR-016。
- **宿主加载客户端产物时出错**：产物自身不抛错，其他插件的加载不受牵连；见 FR-015。
- **宿主翻译函数回显 key**（命名空间未注册时把 `copySource` 原样返回，而不是返回空串或抛错）：按"未解析"处理，改用插件自带文案；见 FR-008 与 SC-009。
- **插件已安装但从未生效**（服务缺失导致启动即降级）：会话里仍是完整可读的代码块，不出现空白或错误占位。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 把会话消息中标记为 mermaid 的代码块在原位置显示为图，不改变消息顺序与其他内容。
- **FR-002**: 系统 MUST NOT 为显示图而打开侧栏、生成文件或新增会话条目。
- **FR-003**: 用户 MUST 能在图旁边查看该图的完整源码并复制。
- **FR-004**: 当图无法渲染（语法错误、超出规模限制）时，系统 MUST 回退为完整的代码块文本，并显示可读的失败原因。
- **FR-005**: 渲染 MUST 在浏览器端完成，运行期不发起任何网络请求，不依赖用户机器上的额外运行时或工具链。
- **FR-006**: 图 MUST 按容器宽度重新排版；页面级不得出现横向溢出，超大图 MUST 在图内缩放或平移。
- **FR-007**: 图的颜色、字体与圆角 MUST 跟随宿主主题，并在主题切换后同步更新。
- **FR-008**: 界面中新增的可见文字（按钮、图的替代文本、失败提示）MUST 在宿主支持的全部 8 种界面语言（`zh`、`en`、`ja`、`es`、`fr`、`de`、`ru`、`pt`）下都可读，语言跟随宿主设置。宿主翻译服务缺失、签名改变、抛错、返回空串、把 key 原样回显、或占位符未被替换时，MUST 回退到插件自带的对应语言文案；任何情况下 MUST NOT 把内部 key（如 `copySource`）显示给用户。
- **FR-009**: 插件被卸载、禁用或渲染层出错时，会话 MUST 回退显示完整文本，且不影响该会话其余消息。
- **FR-010**: 重新安装插件后，此前会话中的图 MUST 恢复为渲染结果，无需迁移或重写历史。
- **FR-011**: 插件启用期间，系统 MUST 让模型知道"mermaid 代码块会被渲染成图"这一事实；插件停用后该信息 MUST 一并消失，避免产生只有插件在场才可读的内容。
- **FR-012**: 该能力 MUST NOT 要求用户修改全局或个人指令文件才能生效；用户对内容形态的偏好属于其个人配置，不在插件内规定。
- **FR-013**: 包清单 SHOULD NOT 声明任何能让宿主在启动前否决本插件的版本要求（例如 `engines.dsh`、dsh 的 peer 版本），也不声明对宿主客户端包的绑定版本；插件在未知版本上 MUST 只是不渲染，而不是被拒绝加载或拖垮启动。
- **FR-014**: 插件启动与运行的任何失败（服务缺失、接口签名改变、注册失败、引擎加载失败、绘制抛错）MUST 被就地捕获，降级为"该处不渲染、显示原文本"，MUST NOT 把异常抛给宿主。
- **FR-015**: 客户端产物 MUST 自身可独立编译与执行；缺少全局加载器、加载器抛错、工厂内部抛错时，产物 MUST NOT 抛出，且 MUST NOT 影响同批加载的其他插件。
- **FR-016**: 宿主派发的数据不符合预期（字段缺失、类型不对、取值器抛错）时，或宿主交来的 `children` 不是 React 能渲染的形状（普通对象、函数、含这些的数组）时，插件 MUST 交回宿主原本的代码块（宿主块不可用时交回源码文本），不得让异常离开这一层，也不得让该消息变成空白。
- **FR-017**: 上述加固 MUST 各有一条可重复的自动化证据（构建期静态检查或浏览器故障注入），并在文档中与要求逐条对应。
- **FR-018**: 图 MUST 对读屏软件是一个带本地化名称的图像，且该名称 MUST NOT 混入引擎类型等技术标记；引擎自带的缩放按钮 MUST 位于图像之外、可被键盘聚焦；复制结果 MUST 既有可见文字提示、也经礼貌级实时区域播报，不得只有其中一种。

### Key Entities *(include if feature involves data)*

- **图源**：会话历史中的一段 mermaid 文本；是不可再生的信息本体，必须始终可读、可检索、可复制。
- **渲染结果**：由图源派生出的矢量图与交互控件；可随时丢弃并由图源重建，不入库。
- **插件安装态**：启用 / 停用；决定图源被渲染还是原样显示，不改变图源本身。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 打开含 20 个节点以内的图，图在 1 秒内出现，且不阻塞消息其余内容的阅读。
- **SC-002**: 卸载插件后，历史会话中 100% 的 mermaid 代码块以完整文本呈现，可复制、可被会话检索命中。
- **SC-003**: 视口宽 360 像素时，页面级横向溢出为 0；图内文字不小于正文最小字号。
- **SC-004**: 断网环境下完成一次完整渲染，外部请求数为 0。
- **SC-005**: 深浅主题各切换一次后，图配色与宿主一致，且无需刷新页面。
- **SC-006**: 用 7 类畸形宿主（缺全局加载器、加载器抛错、工厂抛错、缺 slots 服务、接口签名改变、翻译函数抛错、翻译函数把 key 原样回显）驱动插件，宿主侧不抛出任何异常，插件均降级为不渲染或使用自带文案。
- **SC-007**: 发布包的清单中版本否决类字段数量为 0；在"宿主版本未知"的模拟环境下，插件不被拒绝加载。
- **SC-008**: 构建期静态检查覆盖 FR-013～FR-016，任一条不满足则构建失败、不产出可安装包。
- **SC-009**: 8 种界面语言各驱动一次，图的无障碍名与两个按钮文案均为该语言的可读短语，出现 camelCase key 的次数为 0。
- **SC-010**: 逐项断言 `role="img"` 只落在 `svg` 上且全图只有一个、容器是 `role="group"`、图像没有 `aria-roledescription`、缩放按钮不在图像节点内且文案为界面语言、复制结果既出现在可见文字里也出现在 `role="status" aria-live="polite"` 的区域里。

## Assumptions

- 目标读者使用 DSH 的 Web 界面（含桌面应用内嵌页面）。宿主仍在快速迭代，因此本期以"在未知版本上也只降级、不否决"为兼容目标，而不是把版本对齐到某一个具体发行版。
- 会话历史中保存的是消息原文，因此"文本即图源"的前提成立。
- 阅读偏好（例如"尽量用图表达"）由使用者自己写进指令文件；本功能只负责"画得出来"，不替使用者决定什么时候画。
- 图的绘制能力由插件自带，不需要使用者额外购买或配置任何服务。
- 本期只处理 mermaid 代码块这一种图源；其他图形格式另立功能。
