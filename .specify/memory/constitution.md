# DSH-Dyslexia Constitution

## Core Principles

### I. 默认带偏好，但界面上可见可关

插件 MUST 提供能力（渲染什么、怎样渲染），并 MUST 让读者看得见它的默认行为，不得在读者不知情处改变内容形态。
插件 MAY 默认携带一条面向模型的内容偏好（例如"图更省力时优先用图"），前提是四条同时成立：

1. 偏好在界面上可见、可由读者一键开关，不需要编辑任何指令文件；
2. 偏好文本给出判据（何时用、何时不用），MUST NOT 使用"每次""必须"这类无条件要求；
3. 关闭偏好后，插件行为 MUST 与"没有这条偏好"的版本逐字等价；
4. 偏好的存在与状态 MUST 在交付说明中写明，不得暗示"插件中立"。

读者的个人化偏好（用哪种图、写多长、结尾几条）仍属于使用者配置，写在项目或全局 `AGENTS.md`。

理由：只渲染而不鼓励输出时，阅读障碍读者仍须自己想到"请画图"才有收益；把偏好做成可见、可关的开关，
比藏在指令文件里更可控，也不剥夺模型在具体情境下的判断。修订记录：1.0.0 的"能力与偏好分离"禁止插件携带
任何偏好；2.0.0 改为"默认带偏好，但界面上可见可关"，因为 feature 002 的读者明确要求"装上就更积极画图"，
同时保留关掉开关回到 001 的纯能力行为。

### II. 零环境假设

任何产物 MUST NOT 假设使用者机器上安装了特定语言运行时、包管理器、字体或第三方库。
需要外部工具时，由 Agent 在运行期依据当前环境自行判断；插件与指令不得预先宣称"已安装"某物。

理由：插件会被分发到陌生机器，假设一旦不成立就是启动即失败。

### III. 依赖自包含

DeepSeek Harness 未自带的依赖 MUST 打包进插件本体，运行期零网络请求、零 CDN 加载。
纯指令场景允许 Agent 现场安装依赖，插件场景不允许；两者的可交付性判定不同，不得混用。

理由：插件在会话内被激活，没有"安装阶段"可以失败重试；一个需要联网取资源的渲染器会在离线或墙内环境直接失效。

### IV. 降级不丢数据

所有可视化表达 MUST 以纯文本为信息本体（代码块、表格、SVG 等文本格式），渲染器只是叠加层。
插件被卸载、渲染出错或宿主升级移除挂载点时，历史内容 MUST 仍以可读、可检索的文本形式呈现，信息不丢失；
重新安装 MUST 能让旧历史恢复为图形，因为源文本从未被改写。

理由：会话历史是长期资产；二进制产物（PNG 等）不可检索、不可 diff、只增不减，与"可事后检索"的目标直接冲突。

### V. 窄屏先行

渲染结果 MUST 适配手机与平板的窄视口：按容器宽度重新排版而非缩放整图，禁止固定像素宽度，
溢出时在消息内部横向滚动而不是撑破页面。宽屏优化不得以牺牲窄屏可读性为代价。

理由：阅读障碍读者常在手机上继续会话；会话界面本身就是响应式的，插件不能成为例外。

## 技术约束

- **跟随宿主契约**：颜色、字体、圆角 MUST 取自宿主主题变量；界面文字 MUST 走客户端本地化服务；不引入第二套主题系统。
- **挂载点最小化**：优先选择"可叠加的渲染层"这类无状态扩展点；不得为可视化新增会话实体（自定义节点、事件、工具调用），
  因为会话实体卸载后会留下无主记录。
- **不接管宿主界面**：不替换应用根节点、不修改宿主 DOM 或样式、不复制宿主内部组件源码来估算布局。
- **自包含交付**：插件包 MUST 能在无构建工具的机器上安装（不依赖安装期脚本、不依赖外部构建产物），
  并随包提供许可声明、图标与中英文本地化元数据。

## 开发与验证流程

- 每个功能按项目 `AGENTS.md` 的任务路由选择流程；首次 Feature SDD 前先建立并批准本 Constitution。
- 渲染器类改动的验收 MUST 包含三项证据：装了插件时可见图形、卸载后回退为文本、窄视口下不溢出。
  仅"安装成功"或"挂载点已注册"不构成验收。
- 依赖打包 MUST 在打包后核对实际文件列表与体积，并在无网络条件下重跑一次。
- 无法验证的项（例如需要用户真实设备、真实会话环境）MUST 在交付说明中标注为未验证，不得以推断代替观测。

## Governance

- 本 Constitution 优先于项目的其他开发习惯；与 `AGENTS.md` 冲突时以本文件为准，并据以修订 `AGENTS.md`。
- 修订需给出变更理由、受影响的既有产物与迁移方式；批准后按语义化版本递增
  （移除或重定义原则为 MAJOR，新增原则或实质扩写为 MINOR，措辞澄清为 PATCH）。
- 每次 Feature 的计划阶段与验收阶段 MUST 检查是否违反五项原则；违反项必须在计划中给出理由或改写方案。
- 运行时开发指引以项目 `AGENTS.md`、`.agents/skills/**` 与 `.specify/**` 为准。
